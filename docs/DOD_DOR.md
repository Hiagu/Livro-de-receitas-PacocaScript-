# Acordos de Qualidade da Equipe

## Definition of Ready (DoR)
Uma Issue só pode ser assumida por alguém quando:
- [ ] Tem título claro no padrão `[Receita] <Nome> - <Categoria>`
- [ ] Está escrita no formato Como / Quero / Para que
- [ ] Indica a persona beneficiada (Guilhemer Silva ou Márcia Sousa, definidas em docs/PERSONAS.md)
- [ ] Tem a categoria definida (ex.: saladas, carnes, sopas, massas, sobremesas)
- [ ] Tem pelo menos 2 critérios de aceitação em checklist
- [ ] Tem a label `user-story` e cita o épico pai

## Definition of Done (DoD)
Uma entrega só está concluída quando:
- [ ] Segue o template de receita do repositório (título, ingredientes, modo de preparo e rodapé de navegação)
- [ ] Todos os links foram testados e funcionam (menu e rodapé)
- [ ] O texto está sem erros de ortografia
- [ ] Os critérios de aceitação da Issue foram atendidos
- [ ] O Pull Request tem 3 aprovações
- [ ] O merge na main foi feito sem conflitos
