# Livro de Receitas Colaborativo - PacocaScript


## Descrição Geral
Este é o Livro de Receitas Colaborativo da equipe **PacocaScript**, desenvolvido como atividade prática para a disciplina de Engenharia de Software na turma do 2® modulo do curso tecnologo de Análise e Desenvolvimento de Sistemas - IFPI campus Piripiri 2026. 

O objetivo principal é aplicar os conceitos de Gerência de Configuração de Software (SCM), utilizando o **Git** e o **GitHub** para organizar, controlar e rastrear mudanças.

## como contribuir 
Toda nova receita deve seguir um fluxo: 

1. **Abra uma Issue:** Utilizando o padrão `[Receita] <Nome> - <Categoria>`.
2. **Crie uma Branch:** A partir da `main`, seguindo o padrão `feature/<categoria>-<nome-da-receita>`.

3. **Faça Commits Semânticos:** Use `feat:` para a receita e `docs:` para atualizar o menu.md .
4. **Abra um Pull Request:** Inclua a descrição clara e a palavra-chave `Closes #<numero-da-issue>`.
5. **Code Review:** Todo PR deve ter **no mínimo 3 aprovações** antes do merge na `main`.

> **Importante:** Antes de contribuir, leia as regras completas e os modelos de Issue/PR no nosso arquivo **[CONTRIBUTING.md](CONTRIBUTING.md)**.
